# Plusma — revised logo

The new standalone symbol is an original rounded P silhouette with a plus-shaped negative-space counter. It replaces the Startease orbit completely. The lavender palette and Startease ExtraBold wordmark retain a family resemblance. The original design is preserved in `v1/`.

- `plusma-logo.svg` / `.png`: transparent lockup for dark backgrounds.
- `plusma-logo-light.svg` / `.png`: transparent lockup for light backgrounds.
- `plusma-logo-black` / `plusma-logo-white`: monochrome lockups.
- `plusma-symbol.svg` / `.png`: standalone symbol, transparent background, no wordmark.
- `plusma-symbol-black` / `plusma-symbol-white`: monochrome standalone symbols.
- `plusma-favicon.svg` / `.png` / `.ico`: dark tile with lavender symbol.
- `plusma-preview.png`: complete presentation.
- `plusma-symbol-preview.png`: symbol-only presentation.
- `plusma-favicon-sizes.png`: 16, 32, and 48 pixel raster checks enlarged 4×.

All SVGs use paths and need no font installation. Lockup PNG: 2200 × 560. Symbol PNG: 1024 × 1024.

Installed in `apps/space/app/icon.svg`, `apps/space/app/favicon.ico` (16, 32, 48, 64, 128, 256 px), and `apps/space/app/apple-icon.png` (180 px). Next.js automatically generates their metadata links via its file conventions.

Palette: lavender #B8ACFF, light-background lavender #8B79E6, ink #18171D.

Typography source: Startease ExtraBold 3, derived from Plus Jakarta Sans by Tokotype, SIL OFL 1.1. See AUTHORS.md and OFL.txt. No font software bundled.
