# Startease ExtraBold

Base font: Plus Jakarta Sans by Tokotype.

Copyright 2020 The Plus Jakarta Sans Project Authors
(https://github.com/tokotype/PlusJakartaSans).

Custom Startease outline reconstruction, reference-wordmark ligature,
reference spacing, 57 redesigned basic-Latin letters and numerals in version 3,
five preserved reference lowercase letters, optical curve construction,
proportional/tabular/small numeral sets, optical spacing, rebuilt ligatures,
naming, packaging and specimen: Startease, 2026.

The source reference was provided and selected by the Startease brand owner.
The custom wordmark was reconstructed from that supplied raster reference.
