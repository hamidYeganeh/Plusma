# Plusma logo

Native vector artwork based on the adjacent Startease brand assets. The wordmark spells **Plusma**, using the Startease ExtraBold 3 glyph outlines with tightened spacing. The orbit echoes Startease; a rounded plus replaces its star.

- `plusma-logo.svg` / `.png`: white wordmark, lavender symbol, transparent background; use on dark backgrounds.
- `plusma-logo-light.svg` / `.png`: dark wordmark, deeper lavender symbol; use on light backgrounds.
- `plusma-logo-black.svg` / `.png`: single-color dark artwork.
- `plusma-logo-white.svg` / `.png`: single-color white artwork.
- `plusma-symbol.svg` / `.png`: standalone symbol, transparent background.
- `plusma-preview.png`: presentation proof.

Every SVG uses paths; no font installation is required. Logo PNG files are 2200 × 560 pixels. Symbol PNG is 1024 × 1024.

Colors: Startease lavender #B8ACFF, light-background lavender #8B79E6, ink #18171D.

Typography source: Startease ExtraBold 3, derived from Plus Jakarta Sans by Tokotype; licensed under SIL OFL 1.1. See AUTHORS.md and OFL.txt. No font software is bundled.
