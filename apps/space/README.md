# Space

برنامه عمومی پرسه. از ریشه مخزن:

```sh
npm run dev --workspace space
```

مسیرهای فعلی: `/` و `/cafe/barg`. alias `/cafe/barg/explore` به مسیر کافه هدایت می‌شود.

catalog محلی: `modules/cafes/catalog.ts`؛ نمایش: `modules/explore`؛ پیش‌نمایش رزرو محلی: `modules/reservations`؛ ترجمه: `messages/fa.json`؛ کیت: `packages/ui`.
