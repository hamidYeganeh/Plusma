# فازبندی

تاریخ مبنا: ۲۰ اکتبر ۲۰۲۶. زمان‌ها پس از بازخورد پایلوت برآورد می‌شوند.

| فاز               | خروجی                                                                   | معیار عبور                                                                                         |
| ----------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| ۰ · دموی فعلی     | کافه برگ، فهرست محلی، نمایشگر، انتخاب میز، پیش‌نمایش رزرو و طراحی فارسی | بازدید قابل استفاده روی گوشی؛ ساخت/lint/typecheck؛ مسیر نامعتبر؛ خروج و ورود مجدد بدون کنترل مضاعف |
| ۱ · قالب چند مکان | کافه دوم واقعی، فرایند برداشت و انتشار صحنه                             | کافه دوم بدون کپی قالب و تغییر قواعد حرکت؛ شباهت و مقیاس تأییدشده                                  |
| ۲ · رزرو          | backend و پنل، منابع پایدار، نگه‌داشت و ظرفیت                           | رزرو هم‌زمان، جداسازی مشتریان، لغو و اطلاع‌رسانی آزموده‌شده                                        |
| ۳ · منو و سفارش   | منوساز، قالب‌ها، سفارش، پرداخت                                          | قیمت معتبر، وضعیت سفارش و verify پرداخت؛ عملیات تکراری بدون ثبت دوباره                             |
| ۴ · صندوق         | اجرای محلی، SQLite و sync؛ سپس سخت‌افزار مشخص                           | بازیابی از قطع اینترنت/خرابی، دنگ و تطبیق پرداخت؛ پایلوت یک صندوق اصلی                             |
| ۵ · صنف دوم       | ملک یا گالری به انتخاب بازار                                            | قواعد همان حوزه مستقل؛ استفاده مجدد از نمایشگر و مکان                                              |

هر فاز باید مستقل قابل نمایش و آزمون باشد. فولدر، زیرساخت یا adapter فرضی برای همه فازها از ابتدا ایجاد نمی‌شود.

## ترتیب همین فاز

۱. انتقال هندسه موجود و ساخت lifecycle مشخص.
۲. route عمومی و catalog محلی.
۳. کیت، design.md، next-intl و next-themes.
۴. بررسی دسکتاپ و گوشی، آزمون مسیر‌یابی و خروج/ورود.
۵. ارائه به کافه برگ و ثبت بازخورد؛ بدون افزودن فرم رزرو غیرعملیاتی.
