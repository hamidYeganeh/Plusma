# ابتدا نمایش محلی کافه

برای ارائه سریع به کافه برگ، داده عمومی مکان از catalog داخل `space` و صحنه از فایل‌های پروژه خوانده می‌شود. کاربر صریحاً backend و قابلیت‌های عملیاتی را به بعد موکول کرد؛ ساخت آن‌ها اکنون با KISS و محدوده دمو ناسازگار است.

تغییر محتوای اولیه به build/deploy نیاز دارد. در عوض دیتابیس، شبکه و مدیریت داده مهمان وارد این فاز نمی‌شوند. مسیر اصلی `/cafe/[slug]` است؛ `/explore` فعلاً alias هدایت‌شونده است.

تعویق backend و رزرو در ۲۴ اکتبر با درخواست کاربر و [ADR-0006](0006-operational-reservations.md) برای رزرو عملیاتی جایگزین شد.
