# نقشه مستندات

آخرین تنظیم محدوده: ۲۴ اکتبر ۲۰۲۶. نمایش سه‌بعدی، رزرو عملیاتی، منو و گردش سفارش با NestJS و PostgreSQL پیاده شده‌اند.

[راهنمای افزودن کسب‌وکار](guides/adding-a-business.md) قرارداد توسعهٔ صنف بعدی را شرح می‌دهد؛ رزرو عملیاتی طبق [ADR-0006](adr/0006-operational-reservations.md) و [راهنمای اجرا](guides/running-reservations.md) اضافه شده است.

## ترتیب مطالعه

پروپوزال ← فازبندی ← بلوپرینت ← اصول مهندسی ← ADRها. برای تغییر ظاهر از راهنمای طراحی و برای افزودن کافه از راهنمای محتوا شروع کن.

وضعیت‌ها: **پیاده‌شده** یعنی در کد حاضر است؛ **برنامه‌ریزی‌شده** یعنی هدف آینده؛ **پیشنهادی** یعنی تصمیم نهایی نشده. وجود یک قابلیت در پروپوزال به معنی پیاده‌شدن آن نیست.

مرحله منو و سفارش در [ADR-0007](adr/0007-cafe-menu-and-orders.md) و مرجع ظاهر Luma در [گزارش طراحی](design/cafe-workspace.md) ثبت شده است.
