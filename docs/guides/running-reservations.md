# اجرای رزرو واقعی

این برش از انتخاب میز در صحنه تا نگه‌داشت ظرفیت، ثبت اطلاعات مهمان، تأیید، پیگیری و لغو کار می‌کند. کارکنان از `/staff` فهرست روز را می‌بینند و ورود یا لغو را ثبت می‌کنند. جزئیات راه‌اندازی و HTTP در [API README](../../apps/api/README.md) و تصمیم‌ها در [ADR-0006](../adr/0006-operational-reservations.md) است.

```sh
npm ci
npm run setup:local
npm run db:up
npm run db:migrate
npm run db:seed
npm run dev
```

برای ورود کارکنان، دستور `staff:create` در README را با رمز انتخابی اجرا کن. هیچ رمز پیش‌فرضی در seed وجود ندارد. دو کافه نمونه هر کدام سازمان مستقل دارند. انتخاب روز بر اساس زمان تهران است؛ زمان آزاد و ظرفیت از NestJS می‌آیند. اگر backend در دسترس نباشد رابط پیام خطا و تلاش مجدد نشان می‌دهد.

پیش‌فرض فعلی هر رزرو ۹۰ دقیقه، نگه‌داشت ۵ دقیقه و تخصیص کامل یک میز است. تماس مهمان هنوز با پیامک احراز نمی‌شود. داده‌های اولیه برای اجرای محلی هستند و تعهد پذیرش از طرف کافه واقعی ایجاد نمی‌کنند. ساعت کاری و ظرفیت عملیاتی باید پیش از انتشار با کسب‌وکار هماهنگ شوند.

قفل میز و محدودیت PostgreSQL مانع رزرو هم‌پوشان می‌شوند. درخواست تکراری با همان کلید، رزرو تازه نمی‌سازد. مجوز کارمند روی سازمان و مکان بررسی می‌شود؛ کد پیگیری به‌تنهایی مجوز لغو نیست. توکن مهمان در همان زبانه مرورگر نگه‌داری می‌شود و بازیابی پس از بسته‌شدن آن هنوز فلو احراز تماس لازم دارد.

- [Product Hunt · Tock 2.0](https://www.producthunt.com/products/tock-2-0): مرجع دامنه رزرو مکان و تجربه حضور. هیچ اتصال عملیاتی به Tock ساخته نشده است.

## منو و سفارش

در `/staff` از تب منو اولین آیتم را با قیمت تومان اضافه کن. منوی عمومی از دکمه «منوی کافه» داخل بازدید سه‌بعدی خوانده می‌شود. آیتم ناموجود برای بازدیدکننده نشان داده نمی‌شود.

در تب رزروها، پس از ثبت ورود مهمان و پیش از پایان حضور، «ثبت سفارش» فعال است. آیتم‌ها و تعداد را انتخاب کن؛ قیمت نهایی از سرور می‌آید. از تب سفارش‌ها، آماده‌سازی، آماده‌شدن و تحویل را ثبت کن. روز سفارش بر اساس زمان ثبت آن در منطقه زمانی کافه است. برای بازیابی درخواست با پاسخ نامعلوم، از «بازیابی نتیجه» استفاده کن؛ درخواست جدید تکراری نساز.

پرداخت و صندوق هنوز پیاده نشده‌اند. تحویل سفارش به معنی پرداخت نیست. تصمیم این مرحله در [ADR-0007](../adr/0007-cafe-menu-and-orders.md) و مرجع ظاهر در [پنل Luma](../design/cafe-workspace.md) ثبت شده است.
